# Question format and author review

The prototype pack is a JSON array, validated against `resources/data/question.schema.json` and additional runtime checks in QuestionRepository. The bundled three records cover variables, loop control, and comparison in beginner GDScript 4.6. This is the working curriculum baseline; educational/reviewer approval remains M0-QA.

Each record has unique `id`, `type` (`multiple_choice`, `identification`, `coding_fix`), `difficulty` (`easy`, `medium`, `hard`), `language` (`GDScript`), `language_version` (`4.6`), `prompt`, `answers`, integer `reward` (1–60), and `explanation`. Multiple Choice also requires four distinct `options` and exactly one accepted answer equal to one option. Coding Fix requires exactly one literal `___` in the prompt and accepted replacements only. Identification trims whitespace and ignores case; other types trim surrounding whitespace but preserve code case. No answer is executed.

Runtime validation also enforces unique IDs, non-whitespace text, option-answer membership, exactly one coding blank, and input length bounds. The JSON Schema describes structure; it cannot by itself express all these cross-field checks. Maximum pack size is 500 records and the authoring save accepts at most 1 MB of text. Rewards are provisional per-record values for the first slice; the plan's immutable reviewed reward tiers/published revisions are later content work.

Open Developer from the main menu. Edit the array to change records, or use Add question for an Identification skeleton, then change its type/fields as needed. Validate gives a concrete failure reason. Save writes a temporary file then replaces `user://questions.json`; invalid input never replaces the running pack. Editing is prohibited during any active network session. Startup uses the bundled pack if a custom file is invalid. Share the exact custom pack with the other PC: its canonical content hash must match before joining. Back up the local file before editing if you need manual rollback.

Author checklist: one clear learning target; explicit language/version; no ambiguous answer options; coding prompt explains that only the blank is replaced; accepted alternatives cover the stated scope; explanation teaches the rule; reward fits difficulty and intended solve time. Reviewer checklist: independently solve; check alternatives and case handling; validate in Developer; run both correct and incorrect submissions; ensure no unsupported language mix or arbitrary execution; playtest attention cost. Record author/reviewer identities and review findings in the content PR until immutable publishing metadata is implemented.

The host charges 30 mana for generation, selects the next unused prototype record, validates one submission, and caps awards at 120 gold per rolling minute. This small slice intentionally has no difficulty picker, skip, shuffle, practice, or publish/version archive. The gameplay panel explains that the pack is a three-question prototype.
