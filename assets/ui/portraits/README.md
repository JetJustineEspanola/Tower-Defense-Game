# Tower portraits

Created with the built-in image generation tool, using front-view renders of the project's models as references. Names and prices are scene Label nodes, not baked into images.

## jet.png

Create one square 2D illustrated character portrait for a futuristic fantasy chibi tower-defense game. Reference image shows the exact character design to preserve: Jet, young male with short rounded black hair, brown eyes, charcoal black jacket with red piping, red energy sword. Translate the 3D reference into polished anime 2D game portrait art with clean dark linework, soft cel shading, expressive confident face. Chest-up crop with head fully inside frame, character fills 85% of canvas, include signature weapon/shield/coin at lower edge. Dark navy atmospheric background with subtle red rim lighting. No text, no name, no UI border, no watermark. Consistent chibi male proportions, not realistic.
